# راهنمای ساده نسخه ۷ — استودیوی انتخاب طراحی

این نسخه برای تصمیم‌گیری استاد درباره **ظاهر نهایی سایت** ساخته شده است. همه متن‌های داخل سایت و پنل تنظیمات انگلیسی هستند؛ این راهنما فارسی است.

## ساخت و انتشار

۱. در حساب GitHub با نام `AlirezaJalaliUT` یک Repository عمومی به نام `alirezajalaliut7` ایجاد کنید.

۲. فایل ZIP را استخراج کنید. **همه محتویات داخل ZIP** شامل فایل مخفی `.pages.yml` را مستقیم در صفحه اصلی مخزن آپلود کنید؛ پوشه اضافه نسازید.

۳. از Settings > Pages، گزینه Deploy from a branch را انتخاب کنید و main و /(root) را مشخص کنید.

۴. بعد از موفقیت انتشار، سایت باید در نشانی زیر باز شود:

`https://alirezajalaliut.github.io/alirezajalaliut7/`

## استاد چگونه سبک سایت را انتخاب کند؟

- روی دسکتاپ، نوار آیکون‌های سمت چپ دیده می‌شود. روی موبایل، آیکون طراحی در گوشه بالای چپ قرار دارد.
- **Presets:** هشت مجموعه پیشنهادی که چند جنبه طراحی را هم‌زمان تغییر می‌دهند.
- **Colors:** چهارده پالت روشن و سه پالت تیره.
- **Fonts:** هشت ترکیب فونت مستقل.
- **Layout:** چهار چیدمان Hero، چهار زبان طراحی کامل و سه الگوی منو.
- **Details:** تراکم محتوا، فرم گوشه‌ها، حالت کارت‌ها، شیوه نمایش تصویر استاد، پس‌زمینه، اندازه متن و انیمیشن.
- **Save:** ذخیره دو گزینه A/B، دریافت فایل تنظیمات JSON، کپی لینک قابل اشتراک، پیش‌نمایش موبایل و مخفی‌کردن ابزارها برای ارائه.

ترکیب انتخاب‌شده روی همان مرورگر به‌صورت خودکار باقی می‌ماند. برای انتقال دقیق انتخاب به طراح سایت، از قسمت Save گزینه **Download design settings (.json)** یا **Copy shareable design link** را بزنید.

**توجه:** صرفاً انتخاب یک طرح در مرورگر، طراحی پیش‌فرض عمومی سایت را عوض نمی‌کند. برای پیش‌فرض کردن آن در همه دستگاه‌ها باید مقادیر مربوطه را در Pages CMS قسمت **Design Defaults** تنظیم کنید یا فایل JSON را برای اعمال نهایی بدهید.

## مدیریت محتوا

با ورود به https://app.pagescms.org/ و اتصال مخزن GitHub، بخش‌های معرفی استاد، مقاله‌ها، پژوهش‌ها، پروژه‌ها، اعضا، فارغ‌التحصیلان، تدریس، جوایز، اخبار، سخنرانی‌ها، موقعیت‌ها و اطلاعات تماس قابل ویرایش خواهند بود.

**احتیاط:** محتوای نمونه یا اطلاعات فاقد سند را به‌عنوان اطلاعات علمی قطعی منتشر نکنید. فهرست مقالات و مشخصات واردشده از نسخه قبلی، پیش از انتشار رسمی بازبینی شوند.

## تست

ساختار فایل‌ها و تنظیمات YAML کنترل شده‌اند و رابط در مرورگر Chromium با خروجی شبیه‌سازی‌شده بررسی شده است. تست واقعی Jekyll Build در این محیط انجام نشده؛ وضعیت انتشار نهایی را در GitHub Pages بررسی کنید.
